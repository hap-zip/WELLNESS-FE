## 현재 결정사항

- [x] Expo Go 기준으로 먼저 UI 구현

## 브랜치 운영 규칙

- `develop`에는 직접 작업하지 않음
- 화면별 작업 브랜치 형식: `feat/<화면ID>`
- 예시: `feat/auth-01`, `feat/home-01`, `feat/chk-00`
- 한 화면의 UI·동작·검증을 마친 뒤 커밋하고 다음 화면 브랜치로 이동
- 공통 기반 변경은 가장 먼저 진행하는 화면 브랜치에서 작업하되, 이후 화면에도 필요한 경우 별도 커밋으로 분리
- 화면 브랜치 완료 후 `develop`으로 병합

## 집에서 재개할 때

1. 저장소 최신 상태 확인

```bash
git pull
```

2. 의존성 설치

```bash
npm install
```

3. Expo 실행

```bash
npx expo start
```

4. 작업 시작 전에 이 문서의 첫 번째 미완료 `[ ]` 항목 확인

5. 한 화면 단위로 구현하고, 완료 후 체크박스와 작업 로그 갱신

## 작업 원칙

- 완료한 화면은 반드시 실제 렌더링을 확인한 뒤 체크
