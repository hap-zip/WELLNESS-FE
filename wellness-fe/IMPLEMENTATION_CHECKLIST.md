# 몸기록 Expo 구현 체크리스트

회사와 집의 Codex 환경에서 같은 기준으로 이어서 작업하기 위한 인계 문서입니다.

## 현재 결정사항

- [x] Expo Go 기준으로 먼저 UI 구현
- [x] HTML을 WebView로 삽입하지 않고 React Native UI로 재현
- [x] HTML과 동일한 디자인을 목표로 함: 색상, 간격, 타이포그래피, SVG, 상태 변화, 화면 전환
- [x] 화면 ID를 공통 식별자로 사용: `AUTH-01`부터 `EMP-01`까지 총 31개
- [x] 실제 HealthKit·Health Connect는 초기 범위에서 제외하고 수동 입력·더미 데이터로 대체
- [x] AI, SQLite, SecureStore 등은 UI 구현을 방해하지 않는 범위에서 단계적으로 추가

## 현재 프로젝트 상태

- Expo: `^54.0.36`
- Expo Router: `~6.0.24`
- React Native: `0.81.5`
- 현재 기준 브랜치: `develop`
- TypeScript strict 설정 사용
- 인증·온보딩·홈·데일리 체크 1–2단계 화면이 구현됨
- 데일리 체크 1–5단계와 기록 완료 화면이 구현됨

## 브랜치 운영 규칙

- `develop`에는 직접 작업하지 않음
- 화면별 작업 브랜치 형식: `feat/<화면ID>`
- 예시: `feat/auth-01`, `feat/home-01`, `feat/chk-00`
- 한 화면의 UI·동작·검증을 마친 뒤 커밋하고 다음 화면 브랜치로 이동
- 공통 기반 변경은 가장 먼저 진행하는 화면 브랜치에서 작업하되, 이후 화면에도 필요한 경우 별도 커밋으로 분리
- 화면 브랜치 완료 후 `develop`으로 병합

## 집에서 재개할 때

1. 저장소 최신 상태 확인

```bash
git pull
```

2. 의존성 설치

```bash
npm install
```

3. Expo 실행

```bash
npx expo start
```

4. 작업 시작 전에 이 문서의 첫 번째 미완료 `[ ]` 항목 확인

5. 한 화면 단위로 구현하고, 완료 후 체크박스와 작업 로그 갱신
