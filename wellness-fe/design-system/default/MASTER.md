# 몸기록 v8 구현 기준

시각 구현의 유일한 기준은 `Momgirok v8 (offline single file).html`과 동봉된 README다. Foundation의 녹색 계열과 과거 V4의 파란색 계열은 화면 구현에 사용하지 않는다.

## 핵심 토큰

- Canvas `#F1F3F5`, Surface `#FFFFFF`, Text `#16191D`
- Primary `#93C90F`, Primary pressed `#7FAF0C`, Primary soft `#F2F9E2`
- Body/Danger `#FF3B3B`, Recovery `#00A98F`, Data `#0A84FF`
- 화면 좌우 여백 20pt, 섹션 사이 10pt, CTA 높이 54pt, 최소 터치 영역 44pt
- Phone shell은 375pt 기준이며 430pt까지 유동 확장한다. 더 큰 화면에서는 본문 폭을 430pt로 제한한다.
- 제목 24–25/700, 화면 제목 20/700, 섹션 제목 18/700, 본문 14/23, 보조 12.5/18
- pill radius는 999, 카드 16–20, bottom sheet 상단 26

## 구조 원칙

- 흰 섹션은 회색 캔버스 위에 전폭으로 쌓고, 카드가 필요할 때만 내부 카드를 사용한다.
- 홈 기록 전 상태에서도 최근 변화와 오늘의 루틴을 숨기지 않는다.
- 자동 수집 값에는 Apple 건강 출처를, 직접 입력 값에는 직접 입력 출처를 항상 표시한다.
- 차트는 첫 기록부터 보이게 하고, 원인처럼 읽히는 패턴 해석만 30일 이후에 연다.
- 오류에는 재시도와 직접 입력처럼 사용자가 계속 진행할 수 있는 두 번째 경로를 제공한다.
- 아이콘은 `Momgirok Icons.dc.html`의 SVG 체계 또는 앱의 동일 stroke 벡터 아이콘을 사용한다. 구조 아이콘에 이모지를 사용하지 않는다.
- 고정 CTA, 탭바, 입력창은 Safe Area 및 키보드와 겹치지 않게 한다.
- 화면 구현은 장식용 View가 아닌 `Pressable`, 네이티브 picker, 접근성 role/state가 있는 실제 상호작용으로 만든다.

## 화면 범위

홈 4상태와 부위 sheet, 기록 6단계와 완료, 달력과 날짜 상세, 커넥션과 패턴 상세, 루틴 상세/실행/완료/피드백, 웰니스 챗, 마이와 하위 5화면, 스플래시/온보딩/로그인/회원가입/동의/건강 연결을 모두 같은 기준으로 구현한다.

개발 테스트 계정은 제품 UI나 초기값으로 노출하지 않는다. 개발 환경에서만 숨은 제스처로 채울 수 있다.
