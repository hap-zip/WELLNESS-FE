# 몸기록 V4 디자인 시스템 기준

이 파일은 `DESIGN_SYSTEM.md`의 구현 요약이다. 충돌 시 루트의 `DESIGN_SYSTEM.md`가 우선한다.

## 방향

- 이름: Calm Utility
- 성격: 매일 빠르게 기록하고 결과를 이해하는 국내 생활·건강 앱
- 배경: 흰색, 정보 묶음은 부드러운 중립 면
- 구조: 현재 문맥 → 핵심 행동 → 상태 → 다음 행동
- 금지: 편집 문서형 번호, 검은 규칙선, 컬러 레일, AI 장식, 동일 카드 반복

## 토큰

- Text `#17191C`
- Canvas `#FFFFFF`
- Surface subtle `#F6F7F9`
- Border `#E1E5EA`
- Primary `#2F6FED`: 선택·CTA·탐색
- Body `#E5544B`: 신체 불편
- Recovery `#23846B`: 회복·완료
- Warning `#A26A18`: 확인 필요
- Danger `#D44848`: 위험·삭제

## 구성 규칙

- 제목은 24~28pt, 섹션은 20pt, 본문은 16/24를 기본으로 한다.
- 800~900 굵기, 영문 키커, 목록 앞 01/02 번호를 사용하지 않는다.
- 카드는 서로 다른 정보나 행동 범위를 묶을 때만 사용한다.
- 기본 CTA와 선택 상태는 Primary 블루로 통일한다.
- 터치 영역은 iOS 44pt, Android 48dp 이상이다.
- 고정 요소는 세이프에리아와 키보드를 침범하지 않는다.
- 기능, 라우트, API 계약은 보존하되 이전 시각 구조는 보존하지 않는다.

## 화면별 규칙

- 홈: 기록 시작이 최우선이며 기록 후에는 상태, 부위, 다음 행동 순서로 전환한다.
- 기록: 달력과 날짜 상태를 한 덩어리로 읽히게 하고 빈 날짜는 기록 CTA를 제공한다.
- 커넥션 뷰: 기간, 기준선, 지표, 차트, 패턴을 독립된 분석 묶음으로 구분한다.
- 챗: 일반 대화 흐름과 고정 입력창을 사용하고 캐릭터·번호 목록·답변 레일을 금지한다.
- 마이·설정: 프로필과 상태를 먼저 보여주고 목적별 그룹으로 탐색한다.
