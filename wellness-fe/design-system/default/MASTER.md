# 몸기록 디자인 시스템 기준

UI UX Pro Max 검색 결과는 탐색 자료로만 사용한다. 몸기록의 실제 제품 기준은 프로젝트 루트의 `DESIGN_SYSTEM.md`와 `src/theme/tokens.ts`다.

## 선택한 방향

- 제품 유형: 개인 웰니스 기록·발견 도구
- 스타일: 차분한 에디토리얼 미니멀
- 밀도: 중간
- 모션: 상태 중심의 절제된 네이티브 전환
- 핵심 인상: 신뢰, 사생활 보호, 읽기 쉬운 기록

## 제외한 검색 결과

- 시안용 청록색 랜딩 팔레트
- 과장된 대형 마케팅 타이포
- 앱스토어 랜딩 구조
- GSAP 기반 스크롤 연출

이 항목들은 실제 React Native 건강 기록 서비스의 흐름과 맞지 않아 적용하지 않는다.
