# 몸기록 V3 전면 교체 실행 계획

기준일: 2026-08-09

## 현재 판정

V3 코드 교체와 정적 검증은 완료했다. 다만 실제 기기 캡처와 작은 화면·큰 글자 검증 전이므로 디자인 승인 및 출시 가능 판정은 보류한다. 아래 `[x]`는 코드 반영 또는 정적 검증 완료만 의미한다.

현재 출시 판정을 보류하는 이유는 다음과 같다.

- 실제 기기에서 375pt, 큰 글자, 키보드, 탭바 겹침을 아직 승인하지 않았다.
- VoiceOver·TalkBack 순서와 reduced motion은 실기기 확인이 남았다.
- 캡처 기준의 시각 회귀 검사가 아직 없다.

## 보존 범위

다음만 보존한다.

- Expo Router 경로와 5개 탭의 제품 역할
- 도메인 타입과 API 어댑터
- 저장·로딩·오류·권한·재시도 로직
- 바디맵, 차트, 타이머, 사진, 알림 등 기능 로직
- 접근성 라벨, 뒤로가기 fallback, 세이프에리아 처리

기존 JSX 순서, 카드, 히어로, 채팅 말풍선, 스타일 값과 컴포넌트 조합은 보존 대상이 아니다.
