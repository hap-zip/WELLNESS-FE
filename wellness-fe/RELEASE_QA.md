# 몸기록 출시 전 QA 기록

점검일: 2026-08-09

> 이전 자동 검증 결과는 기능 기준 기록이다. V3 전면 교체 후 전 항목을 다시 실행해야 하며 현재 디자인 QA는 미완료다.

## 점검 결과

아래 자동 검증은 V2 코드에서 얻은 이전 기록이다. V3 코드 적용 후 전부 재실행해야 한다. iOS Simulator 캡처와 VoiceOver 실행 검증도 미완료다.

| 항목 | 결과 |
|---|---|

| Expo ESLint | V2 통과, V3 재실행 필요 |

### 라우트 점검 범위

- 인증·온보딩: 스플래시, 로그인, 회원가입, 안내, 동의, 기본 상태, 건강 연결
- 핵심 탭: 홈, 기록, 커넥션 뷰, 챗, 마이
- 데일리 체크: 자동 데이터, 컨디션, 수면, 불편 부위, 활동·피부, 완료
- 상세 흐름: 날짜 기록, 패턴, 루틴 소개·실행·완료·피드백, 지속 신호
- 전달·설정: 요약 설정·미리보기, 건강 데이터, 알림, 동의·데이터, 계정, 서비스 정보
- 예외: 빈 상태 안내, 잘못된 경로, 전역 렌더링 오류

## 이번 QA에서 수정한 사항

- 홈 알림 버튼에 버튼 역할과 눌림 피드백을 추가했다.
- 홈 부위 상세 시트의 배경 닫기 영역과 시트 내부 조작 영역을 분리해 중첩 버튼 구조를 제거했다.
- 데일리 체크 피부 상태 칩을 최소 44pt로 확장했다.
- 자동 데이터·기록 완료 CTA를 고정 높이에서 최소 높이와 세로 패딩 구조로 변경해 큰 글자 잘림 가능성을 낮췄다.
- 기록 캘린더의 미래 날짜 비활성, 오늘 미기록, 과거 기록 없음 상태를 구분했다.
- 차트에는 시각 정보 외 최근 값 목록과 선택 날짜 상세를 유지한다.
- API 응답에서 UI 색상 값을 제거했다. 기존 흰색·잉크·코랄 팔레트 완료 판정은 폐기하며 V3 토큰으로 재검증한다.
- 파란 Expo 기본 앱 아이콘·스플래시를 몸기록 전용 벡터 심볼 기반 자산으로 교체했다.

## 실기기에서 남은 확인

아래 항목은 코드를 보고 완료 처리할 수 없으며 실제 기기 또는 시뮬레이터가 필요하다.

- iPhone SE 계열과 Dynamic Island 기기의 세로·가로 화면
- 대표 Android 소형·대형 화면과 시스템 뒤로가기
- 최대 Dynamic Type에서 헤더, 선택 UI, 하단 CTA 줄바꿈
- VoiceOver·TalkBack 초점 순서와 모달 진입·복귀
- 키보드를 연 챗·로그인·계정 화면의 입력창 가림 여부
- 바디맵 터치, 차트 날짜 선택, 루틴 타이머, 챗 장문 스크롤 체감 성능
- 최종 PDF와 동일 기기 크기의 화면 캡처 비교

## 실기기 QA 순서

1. 신규 사용자 흐름: 스플래시 → 로그인/가입 → 온보딩 → 홈
2. 기록 흐름: 홈 부위 선택 → 데일리 체크 5단계 → 완료 → 기록 상세
3. 발견 흐름: 커넥션 기간·지표 선택 → 날짜 상세 → 패턴 상세
4. 루틴 흐름: 추천 → 타이머 → 중단/완료 → 효과 피드백 → 지속 신호
5. 전달 흐름: 챗 사진 권한 → 답변 실패 재시도 → 요약 생성·복사·저장·공유
6. 설정 흐름: 건강 데이터 → 알림 → 동의·삭제 → 계정 → 서비스 정보
7. 접근성 흐름: 최대 글자, 화면 읽기, 감소된 모션, 고대비 설정으로 1~6 반복
